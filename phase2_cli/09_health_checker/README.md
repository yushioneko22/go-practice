# 09 Health Checker (死活監視ツール)

Webサイトが正常に動いているか、HTTPリクエストを送って確認するツールを作成します。これは Phase 3（Webサーバー開発）への大きな足掛かりになります。

## 1. 基本解説
### `net/http` パッケージ
GoでHTTP通信を扱うための極めて洗練されたパッケージです。
- `http.Get(url)`: 指定したURLにGETリクエストを送ります。
- `resp.StatusCode`: 200 (OK) や 404 (Not Found) などの応答コードを取得します。

### `time` パッケージによる制御
- `time.Duration`: 時間の長さ。
- `time.Sleep(2 * time.Second)`: 指定時間、処理を停止させます。

## 2. 重要なTips
> [!TIP]
> 1. **Bodyのクローズ**: `Get` などでレスポンスを受け取ったら、必ず `resp.Body.Close()` を呼び出す（通常は `defer` を使用）必要があります。これを怠ると、リソース（ファイルディスクリプタ）が枯渇してクラッシュの原因になります。
> 2. **タイムアウトの設定**: 応答が遅いサーバーをずっと待っているとプログラムが詰まってしまいます。`http.Client` に `Timeout` を設定するのが実務の常識です。
> 3. **並行処理との組み合わせ**: 07章で学んだゴルーチンを使えば、100個のサイトを一瞬で同時にチェックすることが可能になります。

## 演習問題 I/O
### 仕様
1. チェックしたいURLのリスト（スライス）を用意する。
2. それぞれのURLにアクセスし、ステータスコードを判定する。
3. エラー（通信不可）の場合の処理も記述する。

## 実行方法
```bash
cd exercise
go run main.go
```
