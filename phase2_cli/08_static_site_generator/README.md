# 08 Static Site Generator (静的サイト生成ツール)

Markdown形式のファイルを読み込み、HTMLに変換してWebページを生成するツールを作成します。これは `Hugo` や `Jekyll` といったツールのミニマム版です。

## 1. 基本解説
### `text/template` パッケージ
Goの標準ライブラリには、強力なテンプレートエンジンが含まれています。
- `{{.Name}}`: 構造体の `Name` フィールドを流し込む
- `{{range .Items}}...{{end}}`: リストをループして表示する

### ファイル操作の復習
このプロジェクトでは「フォルダを走査する (`filepath.Walk`)」「ファイルを読み込む」「新しいディレクトリを作成する」「HTMLを書き出す」といった操作を組み合わせます。

## 2. 重要なTips
> [!TIP]
> 1. **外部ライブラリの検討**: 標準ライブラリだけでMarkdownをパースするのは大変なので、実務では `gomarkdown` などの定評あるライブラリを使うのが一般的です。今回は「変換の仕組み」を学ぶため、簡易的な置換で挑戦しましょう。
> 2. **実行ディレクトリ**: `os.Getwd()` や パス操作 (`path.Join`, `filepath.Base`) を駆使して、どこで実行しても意図した場所にファイルが生成されるように設計します。
> 3. **テンプレートの分離**: HTMLの骨組み（header, footer）を別途用意しておくと、デザインの修正が楽になります。

## 演習問題 I/O
### 仕様
1. `posts/` フォルダ内の `.md` ファイルを探す。
2. その内容を HTML テンプレートに埋め込む。
3. `dist/` フォルダに HTML ファイルを書き出す。

## 実行方法
```bash
cd exercise
go run main.go
# 実行後、dist/ フォルダにHTMLができていることを確認
```
