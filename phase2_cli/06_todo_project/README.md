# 06 Todo Project (総合演習)

これまでの知識を総動員して、実用的な「Todoリスト管理ツール」を作成します。

## 1. プロジェクトの仕様
このツールには以下の機能を持たせます：
- `add`: 新しいタスクを追加する
- `list`: 現在のタスクをすべて表示する
- `delete`: 指定したIDのタスクを削除する（発展：オプション）
- **保存機能**: データは自動的に `todos.json` というファイルに保存されます。

## 2. 重要なTips
> [!TIP]
> 1. **コードの構造化**: `os.Args[1]` でサブコマンド（`add`, `list` など）を判別し、それぞれの処理を別の関数に分けるとスッキリします。
> 2. **エラー処理の徹底**: ファイルがなかったとき、引数が足りなかったときなど、ユーザーに分かりやすいメッセージを出しましょう。
> 3. **TerraformやDockerとの繋がり**: これらも巨大なCLIツールです。`terraform apply` や `docker run` というサブコマンドの仕組みは、今回の `todo add` と全く同じ原理で動いています。

## 演習問題 I/O
### 動作イメージ
```bash
# タスク追加
go run main.go add "Goの勉強をする"
# -> 出力: 推奨: "Task added: Goの勉強をする"

# 一覧表示
go run main.go list
# -> 出力: "1: Goの勉強をする"
```

## 実行方法
```bash
cd exercise
go run main.go [コマンド] [引数]
```
