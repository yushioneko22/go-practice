# 03 File I/O

ファイルの読み書きはCLIツールの基本です。Goでは `os` パッケージを中心に、`io` や `bufio` を組み合わせて強力な操作が可能です。

## 1. 基本解説
### ファイルの読み込み
最も簡単なのは `os.ReadFile("filename")` です。ファイル全体を一気にメモリに読み込みます。

### ファイルの書き込み
`os.WriteFile("filename", data, 0644)` を使います。
- `0644`: ファイルのパーミッション（権限）を指定します。

### 逐次処理 (`bufio`)
大きなファイルを一行ずつ処理したい場合は `os.Open` と `bufio.NewScanner` を使います。

## 2. 重要なTips
> [!TIP]
> 1. **deferで閉じる**: `os.Open` でファイルを開いたら、直後に `defer f.Close()` を書くのがGoの作法です。
> 2. **エラーチェック**: 存在しないファイルを開こうとした場合などは必ずエラーが返ります。無視せず処理しましょう。
> 3. **書き込みモード**: `os.Create` は常にファイルを新規作成（上書き）します。追記したい場合は `os.OpenFile` で `os.O_APPEND` フラグを使います。
