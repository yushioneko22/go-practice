# 04 Environment Variables

APIキーや実行環境の切り替えなど、プログラムの外側から設定を与える手法として「環境変数」は非常に重要です。

## 1. 基本解説
### 変数の取得
- `os.Getenv("KEY")`: 値を取得します。存在しない場合は空文字が返ります。
- `os.LookupEnv("KEY")`: 値と「存在するかどうか」のフラグを返します。

### 変数の設定
- `os.Setenv("KEY", "VALUE")`: プログラム実行中に環境変数をセットします（そのプログラム内でのみ有効）。

## 2. 重要なTips
> [!TIP]
> 1. **大文字小文字**: 慣習的に環境変数はすべて大文字（`DB_URL` など）で命名されます。
> 2. **デフォルト値の処理**: `os.Getenv` で空文字が返ってきた場合にデフォルト値を設定するヘルパー関数を作ることが多いです。
> 3. **.envファイルの利用**: 実務では `.env` ファイルから読み込む外部ライブラリ（`godotenv` など）がよく使われますが、まずは標準の `os` パッケージを理解しましょう。

## 演習問題 I/O
### 演習1: 環境変数の表示
- 内容: `USER` (または `HOME`) 環境変数を取得して表示してください。

### 演習2: 値の設定と確認
- 内容: `APP_DEBUG=true` をセットし、それを取得して表示してください。

### 演習3: 存在チェック
- 内容: `LookupEnv` を使って、存在しない環境変数を探したときの挙動を確認してください。

### 演習4: 条件分岐
- 内容: `APP_ENV` が "production" なら "本番環境"、それ以外なら "開発環境" と表示するコードを書いてください。

## 実行方法
```bash
# 環境変数を渡して実行
APP_ENV=production go run main.go
```
