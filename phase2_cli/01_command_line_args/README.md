# 01 Command Line Arguments

Goで最もシンプルにコマンドライン引数を取得する方法は、標準ライブラリ `os` パッケージの `os.Args` を使うことです。

## 1. 基本解説
### `os.Args` とは
プログラム実行時に渡されたすべての引数を含む **文字列のスライス** です。

- `os.Args[0]`: 実行プログラム自身のパス（または名前）が入ります。
- `os.Args[1:]`: ユーザーが入力した実際の引数が入ります。

### 注意点
引数が渡されていないのに `os.Args[1]` にアクセスすると、インデックス外エラー（panic）が発生します。必ず `len(os.Args)` で長さをチェックする必要があります。

## 2. 重要なTips
> [!TIP]
> 1. **スライスの活用**: `args := os.Args[1:]` とすることで、プログラム名を除いた純粋な引数リストを簡単に扱えます。
> 2. **型変換が必要**: `os.Args` はすべて「文字列」として取得されます。数値を扱いたい場合は `strconv.Atoi()` などで変換する必要があります。
> 3. **複雑な解析には不向き**: 引数の順番が決まっている簡単なツールには適していますが、「-h」や「--verbose」のようなオプションを扱う場合は、次章の `flag` パッケージが推奨されます。

## 演習問題 I/O
### 演習1: 全引数の表示
- 入力: `go run main.go hello world`
- 出力: `引数の数: 2`, `引数リスト: [hello world]`

### 演習2: 特定の引数取得
- 入力: `go run main.go Gopher`
- 出力: `Hello, Gopher!` (引数がない場合は `Hello, Guest!` と表示)

### 演習3: 数値の計算
- 入力: `go run main.go 10 20`
- 出力: `合計: 30` (ヒント: `strconv.Atoi` を使用)

### 演習4: 実行ファイル名の表示
- 入力: 任意
- 出力: `Program Name: [実行ファイル名]`

## 実行方法
```bash
cd exercise
go run main.go [引数]
```
