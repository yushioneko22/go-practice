# 05 JSON Processing

現在のWeb開発や設定ファイル管理において、JSONは標準的なフォーマットです。Goでは構造体へのマッピングが非常にスムーズに行えます。

## 1. 基本解説
### Marshal と Unmarshal
- **Unmarshal**: JSON文字列を Goの構造体 に変換します。
- **Marshal**: Goの構造体 を JSON文字列 に変換します。

### JSONタグ
構造体のフィールドに ``json:"key_name"`` と書くことで、JSONのキー名とフィールド名を紐づけます。

## 2. 重要なTips
> [!TIP]
> 1. **大文字開始の原則**: JSONに変換したいフィールド、あるいはJSONから受け取りたいフィールドは、必ず **大文字開始（Public）** である必要があります。
> 2. **omitempty**: ``json:"name,omitempty"`` と書くと、値がゼロ値（空文字など）の場合にJSONからそのキーを省略してくれます。
> 3. **構造体のネスト**: JSONが階層構造になっている場合は、Goの構造体もネストさせて定義することができます。

## 演習問題 I/O
### 演習1: 単純なパース
- JSON: `{"id": 1, "name": "Apple"}`
- 出力: 構造体に変換して Name を表示

### 演習2: JSONへの変換
- 内容: 構造体に値をセットし、`json.Marshal` で文字列にして表示してください。

### 演習3: ファイルからの読み込み
- 内容: (発展) 設定ファイル `config.json` を読み込み、その内容を構造体に展開してください。

### 演習4: スライスのJSON
- 入力: JSONの配列 `[{"score": 10}, {"score": 20}]`
- 出力: 各スコアの合計を表示
