# 07 スライディングウィンドウ

このトピックでは、**配列・文字列の連続部分に対する問題を O(n) で解くスライディングウィンドウ**を学びます。

## なぜ必要か

「連続するK個の最大和」「重複なしの最長部分文字列」など、部分配列・部分文字列に関する問題は面接の頻出パターンです。ブルートフォース O(n^2) を O(n) に改善するのがスライディングウィンドウの力です。

## たとえ話

スライディングウィンドウは「電車の窓から見える景色」です。
- 電車（窓）が進むと、左端の景色が消え、右端に新しい景色が現れる
- 窓の中の景色全体を毎回数え直す必要はなく、「消えたもの」と「加わったもの」だけ更新すればよい

---

## example/main.go の解説

### 1. 固定サイズのウィンドウ (10-30行目)

サイズKの連続部分配列の最大和。ウィンドウを1つずつスライドさせる。

### 2. 可変サイズのウィンドウ (32-55行目) ★ここが一番重要

条件を満たす最長/最短の部分配列を探す。左端を縮めるタイミングが鍵。

## 演習問題 I/O

### 演習1: 重複なし最長部分文字列
- 入力: `"abcabcbb"` → 出力: `3`（"abc"）

### 演習2: 最小被覆部分文字列
- 入力: s=`"ADOBECODEBANC"`, t=`"ABC"` → 出力: `"BANC"`

---

## 重要なTips

> [!TIP]
> 1. **固定 vs 可変**: ウィンドウサイズが固定なら右端を進めるだけ。可変なら「条件を満たさなくなるまで左端を縮める」パターン。
> 2. **ハッシュマップとの組み合わせ**: 文字の出現回数を追跡するために `map[byte]int` をウィンドウと併用するのが定石。
> 3. **テンプレート化**: 可変ウィンドウには「右端拡張 → 条件チェック → 左端縮小」の定型パターンがあります。暗記すると応用が利きます。

## 実行方法

cd example
go run main.go
