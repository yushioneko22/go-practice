# 04 DFS / BFS（深さ優先探索 / 幅優先探索）

このトピックでは、**面接で頻出する「グリッド上のDFS/BFS」パターン**を学びます。

## なぜ必要か

迷路の最短経路、連結成分の数え上げ、全パターンの列挙など、探索問題は面接の最頻出カテゴリの一つです。DFSとBFSを使い分けられることが合否を分けます。

## たとえ話

- **DFS（深さ優先）** = 迷路を一本道で奥まで進み、行き止まりになったら引き返す。全探索向き。
- **BFS（幅優先）** = 池に石を投げたときの波紋のように、同心円状に広がる。最短経路向き。

## 重要なTips

> [!TIP]
> 1. **4方向移動の定石**: `dx := []int{0,0,1,-1}`, `dy := []int{1,-1,0,0}` でforループを使うとコードがスッキリします。
> 2. **visited配列**: DFS/BFSでは訪問済みチェックが必須。BFSはキューに入れた時点でvisitedにする（重複挿入を防ぐため）。
> 3. **BFS = 最短の保証**: BFSは「最初に到達した時が最短」という性質があるため、最短経路問題に適しています。DFSでは最短の保証はありません。
