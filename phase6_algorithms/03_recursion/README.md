# 03 再帰

このトピックでは、**面接の基礎体力である「再帰的思考」とメモ化による最適化**を学びます。

## なぜ必要か

木の走査、グラフ探索、分割統治法、バックトラッキングなど、面接問題の大半は再帰を使います。再帰を自在に書けることは面接突破の必須スキルです。

## たとえ話

再帰は「マトリョーシカ人形」です。
- 一番外側の人形を開けると、中にもう一つ小さい人形がある
- それも開けると、さらに小さい人形がある
- 一番小さい人形（ベースケース）に到達したら、外側に戻りながら結果を組み立てる

## example/main.go の解説

### 1. 階乗の計算 (10-20行目)

再帰の最もシンプルな例。`n! = n * (n-1)!`。

### 2. フィボナッチ数列 (22-40行目) ★ここが一番重要

素朴な再帰は O(2^n) で遅い。メモ化で O(n) に改善する過程を見せます。

### 3. 再帰の可視化 (42-55行目)

インデントで再帰の深さを可視化し、呼び出しの流れを追います。

- 入力: base=2, exp=10 → 出力: `1024`

## 重要なTips

> [!TIP]
> 1. **ベースケースを最初に書く**: 再帰関数は必ず「これ以上分解しない条件」から書き始める。忘れると無限再帰でスタックオーバーフロー。
> 2. **メモ化 → DP**: 再帰+メモ化（トップダウン）と動的計画法（ボトムアップ）は表裏一体。面接では両方のアプローチを説明できると良い。
> 3. **スタック深度**: Goのgoroutineのスタックは動的に拡張されますが、100万回を超える深い再帰は避けましょう。
