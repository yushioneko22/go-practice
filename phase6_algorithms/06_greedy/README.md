# 06 貪欲法（Greedy）

このトピックでは、**「今のベストを積み重ねる」貪欲法の考え方と、DPとの使い分け**を学びます。

## なぜ必要か

貪欲法はDPより単純で高速ですが、正しさの証明が難しいです。面接では「なぜ貪欲法が使えるのか」を説明できることが重要です。

## たとえ話

貪欲法は「今この瞬間のベストを選び続ける」戦略です。
- お釣りを渡すとき、一番大きい硬貨から使う → これが最小枚数（日本の硬貨では正しい）
- ただし、硬貨が [1, 3, 4] で6円のお釣りなら、4+1+1=3枚より 3+3=2枚の方が最適 → 貪欲法が失敗する場合もある

## 重要なTips

> [!TIP]
> 1. **貪欲 vs DP**: 「局所的最適 = 全体的最適」が成り立つ場合にのみ貪欲法が使えます。確信がなければDPを使いましょう。
> 2. **ソートが鍵**: 多くの貪欲問題は、まず何かの基準でソートすることから始まります。
> 3. **正しさの証明**: 面接では「なぜ貪欲法で正しいのか」を聞かれます。「交換論法」（別の解を交換しても悪くならない）が定番です。
