# 03 Medium: 木・グラフ

このトピックでは、**再帰的思考を鍛える木・グラフのMedium問題**を解きます。

## なぜ必要か

木・グラフ問題は「再帰で考える力」を問います。面接官は、候補者が再帰的に問題を分解し、ベースケースとリカーシブケースを明確に区別できるかを見ています。

## 重要なTips

> [!TIP]
> 1. **木の問題 = 再帰**: 99%の木問題は再帰で解けます。「左右の子に同じ問題を委譲する」パターン。
> 2. **グラフの問題 = DFS/BFS + visited**: 訪問済みチェックを忘れないこと。
> 3. **BST判定の罠**: 「左 < 親 < 右」だけでなく、「左の部分木全体 < 親 < 右の部分木全体」が必要。上限/下限を渡す再帰を使う。
