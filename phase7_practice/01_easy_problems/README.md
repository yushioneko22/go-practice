# 01 Easy問題集

このトピックでは、**面接のウォームアップとなるEasy難易度の頻出問題**を解きます。

## なぜ必要か

面接の最初の15分で出されることが多いEasy問題。ここで詰まると印象が悪く、難しい問題に進む時間もなくなります。Easy問題は「速く正確に」解けることが重要です。

## たとえ話

Easy問題はスポーツの「ウォームアップ」です。本番で最高のパフォーマンスを出すために、基本動作を体に染み込ませておく必要があります。

---

## example/main.go の解説

### 1. Valid Palindrome (10-35行目) ★ここが一番重要

文字列が回文かどうかを判定。英数字のみ対象、大文字小文字を区別しない。Two Pointersの基本応用。

---

## 演習問題 I/O

### 演習1: Merge Two Sorted Lists
- 2つのソート済みリストをマージ

### 演習2: Best Time to Buy and Sell Stock
- 入力: `[7,1,5,3,6,4]` → 出力: `5`（1で買い、6で売る）

### 演習3: Valid Anagram
- 入力: `"anagram"`, `"nagaram"` → 出力: `true`

---

## 重要なTips

> [!TIP]
> 1. **エッジケースを先に考える**: 空配列、1要素、全部同じ値。これらを最初に確認する習慣をつけましょう。
> 2. **計算量を声に出す**: Easy問題でも「この解法はO(n)です」と言えるとポイントアップ。
> 3. **テストケースを自分で作る**: 面接官が与えたテストケース以外に、自分でエッジケースを追加してテストする姿勢を見せましょう。

## 実行方法

cd example
go run main.go
