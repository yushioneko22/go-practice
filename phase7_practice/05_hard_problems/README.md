# 05 Hard問題集

このトピックでは、**複数テクニックを組み合わせるHard難易度の面接問題**に挑みます。

## なぜ必要か

Google等のトップ企業では、45分の面接でHard問題を1問出されることがあります。完璧に解けなくても、アプローチの方向性と部分的な実装を示せれば評価されます。

## たとえ話

Hard問題は「複数の調理法を組み合わせた創作料理」です。1つのテクニックだけでは解けず、ヒープ+連結リスト、スライディングウィンドウ+ハッシュマップなど、組み合わせが求められます。

---

## 重要なTips

> [!TIP]
> 1. **完璧を求めない**: Hard問題は「思考プロセス」を見せる場。ブルートフォースから始めて段階的に最適化する過程を声に出しましょう。
> 2. **分解する**: 大きな問題を小さなサブ問題に分解する力が問われています。
> 3. **時間配分**: 理解5分、設計10分、実装20分、テスト10分が目安。
