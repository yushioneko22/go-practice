# 04 Medium: 動的計画法

このトピックでは、**面接で最も差がつくDP問題の「状態」と「遷移」を見つける訓練**をします。

## なぜ必要か

DPのMedium問題が解けるかどうかで、面接のレベル感が一段変わります。重要なのは「状態を何にするか」「遷移式をどう立てるか」のパターンを多く知っていること。

## 重要なTips

> [!TIP]
> 1. **まず再帰で考える**: いきなりDPテーブルを書こうとせず、素朴な再帰→メモ化→ボトムアップの順で考える。
> 2. **状態の定義が最重要**: dp[i] が「何を意味するか」を明確に言語化できなければ、遷移式は書けません。
> 3. **小さい例を手で解く**: n=1,2,3 くらいを手で解いて、パターンを発見してから一般化する。

## 実行方法

```bash
cd example
go run main.go
```
