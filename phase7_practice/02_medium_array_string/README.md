# 02 Medium: 配列・文字列

このトピックでは、**Medium難易度の配列・文字列問題をパターン認識で攻略する方法**を学びます。

## なぜ必要か

Medium問題は面接のメインディッシュです。ここで「最適解にたどり着けるか」「コードを正確に書けるか」が合否を分けます。

## たとえ話

Medium問題は「料理のレシピを知っているか」です。個々の食材（データ構造）の扱い方は知っている。問題は「どのレシピ（パターン）を適用するか」を見抜くことです。

## 重要なTips

> [!TIP]
> 1. **パターンを見抜く**: 「連続部分列」→スライディングウィンドウ、「ソート済み+ペア」→Two Pointers、「グループ化」→ハッシュマップ。
> 2. **ブルートフォースから始める**: まず O(n^2) の愚直解を説明し、その後に最適化する過程を見せましょう。
> 3. **コーナーケース**: 空配列、1要素、全部同じ値、負の数を含む場合を必ず確認。
