# 08 Error Handling

Goではエラーを例外として投げるのではなく、普通の「値」として返して処理します。

## 1. 基本解説
### `if err != nil`
Goコードで最も頻繁に見かけるパターンです。関数の最後の戻り値として `error` 型を返し、呼び出し側ですぐにチェックします。

### `errors` パッケージ
- `errors.New("msg")`: 新しいエラー値を作ります。
- `fmt.Errorf("...: %w", err)`: 既存のエラーをラップして、追加の文脈を与えます。

## 2. 重要なTips
> [!TIP]
> 1. **独自のError型**: `Error()` メソッドを持つ構造体を作れば、自分専用の高度なエラー型を定義できます。
> 2. **エラーを無視しない**: `_` でエラーを捨ててはいけません。必ず何らかの処理をするか、呼び出し元に返すのがGoの哲学です。
> 3. **早期リターン (Early Return)**: エラーを見つけたらすぐに `return err` することで、正常系のコードがネスト（深いインデント）に入るのを防ぎます。
