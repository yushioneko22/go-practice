# 04 Loops

Goには `while` や `do...while` はありません。すべての繰り返しは `for` だけで実現します。

## 1. 基本解説
### for の３つの顔
1. **標準的**: `for i := 0; i < 10; i++ { ... }`
2. **条件式のみ**: `for x < 100 { ... }` （他言語の `while` に相当）
3. **無限ループ**: `for { ... }`

### range
スライスやマップの全要素を処理するには `range` を使うのが一般的です。
- `for index, value := range slice { ... }`
- `for key, value := range map { ... }`

## 2. 重要なTips
> [!TIP]
> 1. **ブランク識別子 (`_`)**: `range` でインデックスを使わない場合は、`for _, v := range slice` のように `_` で無視するのがGoの作法です。
> 2. **continue と break**: `continue` は次のループへ、`break` はループを即時終了します。
> 3. **パフォーマンス注意**: `range` で大きな構造体を受け取ると、ループのたびに値のコピーが発生します。大きなデータを扱う場合はポインタのスライスを使うなどの検討が必要です。
