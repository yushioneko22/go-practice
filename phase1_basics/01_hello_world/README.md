# 01 Hello World

Goプログラムの基本構造を学びます。Goは非常に厳格な言語であり、プログラムの最小単位は「パッケージ」です。

## 1. コードの構造
### `package main`
すべてのGoファイルは `package` 宣言から始まります。実行可能なプログラムを作るには、必ず `package main` という名前にする必要があります。

### `import "fmt"`
外部パッケージを利用するために `import` を使います。`fmt`（フォーマット）は、標準出力を扱うための最も基本的なパッケージです。Goでは「インポートしたのに使っていないパッケージ」があるとコンパイルエラーになります。

### `func main()`
プログラムが実行される際、最初に呼び出される関数です。`package main` 内に一つの `main` 関数が存在する必要があります。

## 2. 重要なTips
> [!TIP]
> 1. **go fmtの活用**: Goには標準のコードフォーマッタ `go fmt` があります。インデントやスペースを自動で修正してくれるため、スタイルに悩む必要はありません。
> 2. **Printf vs Println**: `Println` は自動的に改行を追加しますが、`Printf` は `%d`（整数）や `%s`（文字列）などの書式指定子を使って高度な整形が可能です。
> 3. **セミコロン不要**: Goでは行末のセミコロンは不要です。コンパイラが自動的に挿入してくれるので、スッキリしたコードになります。
