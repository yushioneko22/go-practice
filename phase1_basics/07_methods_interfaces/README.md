# 07 Methods and Interfaces

Goにおける「振る舞い」の定義方法です。

## 1. 基本解説
### メソッド
特定の型（構造体など）に紐づいた関数です。
- `func (r Rect) Area() ...`: 値レシーバ。値をコピーして受け取ります。
- `func (r *Rect) Scale() ...`: ポインタレシーバ。中身を直接変更できます。

### インターフェース
「型」が「何ができるか（どのメソッドを持っているか）」を定義したものです。
- Goのインターフェースは **暗黙的** です。ある型がインターフェースで定義されたメソッドをすべて持っていれば、自動的にそのインターフェースを満たしているとみなされます（`implements` キーワードは不要です）。

## 2. 重要なTips
> [!TIP]
> 1. **レシーバのネーミング**: レシーバ名は短く、型の頭文字1文字にするのが一般的です（例: `Rect` なら `r`）。`this` や `self` は使いません。
> 2. **インターフェースの構成**: 小さなインターフェース（1〜2個のメソッド）を組み合わせるのがGoらしい設計です（例: `Reader` と `Writer` を合わせた `ReadWriter`）。
> 3. **ダックタイピング**: 「もしアヒル（Duck）のように鳴き、アヒルのように歩くなら、それはアヒルである」という考え方です。これにより、既存のコードに後からインターフェースを適用することが容易です。
