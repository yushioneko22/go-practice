# 06 Pointers

ポインタは難しく感じられがちですが、Goのポインタは「安全でシンプル」です。

## 1. 基本解説
### アドレス (`&`) と 中身 (`*`)
- `&x`: 変数 `x` がメモリのどこにあるか（番地）を取得します。
- `*p`: その番地（ポインタ `p`）の先にある「実際の値」にアクセスします。これを **デリファレンス** と呼びます。

### なぜ使うのか？
1. **値の書き換え**: 関数に値を渡すとき、Goは通常「コピー」を渡します。関数内で元の変数を変更したい場合は、アドレスを渡す必要があります。
2. **パフォーマンス**: 大容量のデータを関数に渡す際、中身をコピーするより「場所」だけを教えるほうが格段に速いです。

## 2. 重要なTips
> [!TIP]
> 1. **ポインタ演算はなし**: C言語と違い、Goでは `p++` のようなポインタ自体を移動させる計算はできません。これによりメモリ安全性が保たれています。
> 2. **nilチェック**: ポインタのゼロ値は `nil` です。`nil` のポインタをデリファレンスするとクラッシュするため、使う前に `if p != nil` でチェックするのが鉄則です。
> 3. **迷ったらポインタ？**: 小さな型（int, bool）はそのまま渡し、大きな構造体や中身を書き換える必要があるものはポインタで渡す、というのが基本方針です。
