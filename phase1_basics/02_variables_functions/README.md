# 02 Variables and Functions

Goは強い静的型付け言語ですが、柔軟な記述も可能です。

## 1. 基本解説
### 変数宣言
- `var x int = 10`: 明示的な型指定。
- `x := 10`: 型推論を使った短縮宣言。関数内でのみ使用可能です（Goで最も一般的な書き方）。
- 初期値を与えない場合、数値なら `0`、文字列なら `""`（空文字）といった「ゼロ値」が自動的に割り当てられます。

### 関数
`func 名前(引数 型) 戻り値型` の順で記述します。Goの大きな特徴として「複数の値を返す」ことができます（例: `result, err := someFunc()`）。

## 2. 重要なTips
> [!TIP]
> 1. **短縮宣言の使い分け**: 基本は `:=` を使い、パッケージレベルの変数や、明示的な型指定が必要な場合のみ `var` を使います。
> 2. **未使用変数のエラー**: インポート同様、宣言したのに使っていないローカル変数があるとコンパイルエラーになります。
> 3. **可視性（Public/Private）**: 関数名や変数名の頭文字が「大文字」なら別パッケージから参照可能（Public）、「小文字」ならそのパッケージ内限定（Private）になります。
