# 03 Slices and Maps

Goのデータ操作の核となるのが「スライス」と「マップ」です。

## 1. 基本解説
### スライス (Slice)
配列をラップした柔軟なデータ構造です。
- `s := []int{1, 2, 3}`: 初期化。
- `append(s, 4)`: 要素を動的に追加します（元のスライスは変更されず、新しいスライスが返ることに注意）。
- `s[low:high]`: 指定した範囲を切り出せます。

### マップ (Map)
キーと値のペアを保持するハッシュテーブルです。
- `m := make(map[string]int)`: `make` を使って作成します。
- `val, ok := m["key"]`: 値の取得と同時に、キーが存在するかどうかを確認できます（comma ok idiom）。

## 2. 重要なTips
> [!TIP]
> 1. **ゼロ値のMap**: 未初期化のマップ `var m map[string]int` は `nil` です。`nil` マップへの書き込みはパニック（強制終了）を引き起こすため、必ず `make` かリテラル `{}` で初期化しましょう。
> 2. **スライスの効率**: スライスは裏側で配列を参照しています。大きなスライスを一部だけ切り出すと、元の大きな配列がメモリに残り続けることがあります。
> 3. **Mapの順序**: GoのMapは反復処理のたびに順番がランダム（不定）になります。特定の順序が必要な場合は別途ソート済みのキーのスライスを用意する必要があります。
