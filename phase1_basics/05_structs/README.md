# 05 Structs

Goには「クラス」はありませんが、代わりに「構造体（Struct）」を使ってデータを構築します。

## 1. 基本解説
### 定義と初期化
```go
type User struct {
    Name string
    Age  int
}
u := User{Name: "Alice", Age: 20}
```
複数のフィールドを一つの型としてまとめられます。

### 埋め込み（Embedding）
他の言語の「継承」に似た概念として、ある構造体の中に別の構造体を「埋め込む」ことができます。これにより、埋め込まれた側のフィールドに直接アクセスできるようになります。

## 2. 重要なTips
> [!TIP]
> 1. **メモリレイアウト**: 構造体はメモリ上に連続して配置されます。非常に大きな構造体の受け渡しはコピーコストが発生するため、ポインタ（`*User`）を使うのが一般的です。
> 2. **JSONタグ**: Web開発では構造体をJSONに変換することが多いです。`Name string `json:"name"`` のようにタグを書くことで、JSONのキー名を自由に指定できます。
> 3. **コンストラクタ関数**: Goには標準のコンストラクタがありませんが、慣習的に `NewUser` といった名前で初期化を補助する関数を作ることが多いです。
