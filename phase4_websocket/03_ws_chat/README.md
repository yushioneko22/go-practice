# 03 Real-time Chat Project (実践！チャットアプリ開発)

これまでの知識を総動員して、ブラウザから実際に使える**「リアルタイム・チャットアプリ」**を構築します。

---

## 1. プロジェクトの仕様
このツールには以下の機能を持たせます：
- **複数人の同時チャット**: 誰かの発言が全員の画面にリアルタイムで表示される。
- **入退室通知**: 参加・退出時にシステムメッセージが表示される。
- **Webフロントエンド**: ターミナルだけでなく、ブラウザからメッセージを送受信できる画面の作成。

## 2. 実装のツボ
> [!TIP]
> 1. **`text/template` の活用**: Phase 3 で学んだテンプレート機能を使い、チャット画面（HTML）をサーバーから返すようにします。
> 2. **JSON化**: メッセージを単なる文字列ではなく `{"user": "Alice", "body": "Hello"}` といったJSON形式にすると、よりリッチなUIが作れます。
> 3. **goroutine の生存サイクル**: クライアントが切れた時にゴルーチンが正しく終了し、リソースが解放されるかを常に意識してください。

## 3. 構成図
```
[Browser A] <---WS---> [Go Server (Hub)] <---WS---> [Browser B]
   |                      |
 メッセージ送信 ---------> 受け取り
   |                      |
 画面更新 <--------------- 全員に一斉配信
```
