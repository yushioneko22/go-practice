# 06 ヒープ / 優先度キュー

このトピックでは、**面接で「Top K」「中央値」などの問題を効率的に解くためのヒープ（優先度キュー）**を学びます。

## なぜ必要か

「配列からK番目に大きい要素を見つけよ」「データストリームの中央値を求めよ」といった問題は、ソートでは O(n log n) かかりますが、ヒープを使えば O(n log k) で解けます。Goでは `container/heap` パッケージが用意されています。

## たとえ話

ヒープは「病院の緊急度トリアージ」です。
- 患者（データ）が到着するたびに緊急度（優先度）で整理される
- 最も緊急な患者が常に先頭にいて、すぐに取り出せる（O(1)）
- 新しい患者の追加も O(log n) で効率的

MinHeap = 緊急度が低い（値が小さい）順に処理
MaxHeap = 緊急度が高い（値が大きい）順に処理

## 重要なTips

> [!TIP]
> 1. **MinHeap vs MaxHeap**: 「K番目に大きい要素」にはサイズKのMinHeapを使います。直感に反しますが、MinHeapの先頭が「K番目に大きい値」になるのがポイントです。
> 2. **container/heap の罠**: `Push`/`Pop`は直接呼ばず、必ず `heap.Push()`/`heap.Pop()` を使ってください。直接呼ぶとヒープの不変条件が壊れます。
> 3. **中央値 = 2つのヒープ**: MaxHeap（下半分）とMinHeap（上半分）の2つを使うと、中央値を O(1) で取得できます。
