# 05 二分木

このトピックでは、**面接で最もよく出題される「二分木」の走査と再帰的操作**を学びます。

## なぜ必要か

二分木はデータベースのインデックス（B-Tree）、構文解析木、ファイルシステムなど、コンピュータサイエンスの根幹をなすデータ構造です。面接では再帰的思考力を試すために頻出します。

## たとえ話

二分木は「家系図」です。
- 各ノード = 家族の一人（データを持つ）
- 左の子 = 長男/長女
- 右の子 = 次男/次女
- ルート = 家系の始祖

走査（Traversal）は「家族全員を訪問する順番」です:
- **前順（Pre-order）**: まず自分、次に左の家系、最後に右の家系
- **中順（In-order）**: まず左の家系、次に自分、最後に右の家系
- **後順（Post-order）**: まず左の家系、次に右の家系、最後に自分

## 重要なTips

> [!TIP]
> 1. **再帰のベースケース**: 木の再帰では `if node == nil { return }` が必ず最初に来ます。これを忘れるとスタックオーバーフローします。
> 2. **BSTの性質**: 二分探索木（BST）では「左 < 親 < 右」が常に成り立ちます。中順走査がソート済みになるのはこの性質のおかげです。
> 3. **高さと深さの違い**: 深さ（Depth）はルートからの距離、高さ（Height）は葉からの距離です。面接で混同しないように注意。
