# 01 Standard HTTP (標準ライブラリで作る最小サーバー)

このコードは、**「外部からのリクエストを待ち受け、ブラウザに文字を返す」**というWebサーバーの最も根幹となる機能を実現するための最小限のサンプルです。

---

## 1. なぜ必要か
現代のシステム開発において、Webサーバーの仕組みを理解していることは必須です。
実務では「なぜか接続できない」「意図しないレスポンスが返る」といったトラブルが多々発生しますが、標準ライブラリ（フルスクラッチ）の挙動を知っていれば、フレームワークを使っている際の問題解決も格段に早くなります。

## 2. 比喩：サーバーは「24時間営業の受付窓口」
- **IPアドレス/ポート**: お店の住所と入り口。
- **ハンドラ**: 特定の要求に応える「専門の受付担当者」。
- **Listen**: 店を開けて、お客さんが来るのをじっと待つこと。

## 3. コード解説

### 01. ハンドラ関数の定義 (10-14行目)
```go
func helloHandler(w http.ResponseWriter, r *http.Request) {
    fmt.Fprint(w, "Hello, Go Web Server!")
}
```
`http.ResponseWriter` は「返事（Response）を書くための紙」、`*http.Request` は「相手からの手紙」です。

### 02. ルーティングと起動 (18-22行目) ★ここが一番重要
```go
http.HandleFunc("/", helloHandler)
http.ListenAndServe(":8080", nil)
```
`HandleFunc` で「どの道（パス）に来たら誰が案内するか」を決め、`ListenAndServe` でサーバーとしての営業を開始します。

---

## 4. 重要なTips
> [!TIP]
> 1. **ポートの競合**: すでに同じポート（8080など）を別のアプリが使っていると、起動時にエラーになります。その場合は `:8081` などに変更して試してください。
> 2. **`nil` の正体**: `ListenAndServe` の第2引数に `nil` を渡すと、Goがデフォルトで用意している `DefaultServeMux` というルーティング機能が使われます。
> 3. **Ctrl + C で終了**: サーバーは動かし続けるものなので、停止させたいときはターミナルで `Ctrl + C` を押します。

## 5. まとめ
Webサーバーは「リクエストを受けて、レスポンスを返す」というシンプルなやり取りの繰り返しです。この基本を `net/http` で体感しましょう。
