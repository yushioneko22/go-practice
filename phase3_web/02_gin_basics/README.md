# 02 Gin Basics (人気フレームワーク Gin の基礎)

このトピックでは、**「高速かつ機能豊富な Gin フレームワークを使い、効率的に Web API を構築する方法」**を学びます。

---

## 1. なぜ必要か
Go の Web 開発において、最も人気があるのが `Gin` です。
標準ライブラリでは数行かかっていた「JSON の返却」や「パラメータの取得」が、Gin を使うと **たった1行** で記述でき、ボイラープレート（定型文）を大幅に削減できます。

## 2. 比喩：Gin は「フル装備のカフェ」
- **Standard Lib**: 豆、粉、お湯、カップを自分で用意して淹れるコーヒー。
- **Gin**: カフェ。席（ルーティング）、メニュー（メソッド判定）、提供方法（JSON出力）がすべて整っており、注文（コード記述）するだけで最高の一杯（レスポンス）が出てくる。

## 3. コード解説

### 01. エンジンの作成とルーティング (10-15行目) ★ここが一番重要
```go
r := gin.Default()
r.GET("/ping", func(c *gin.Context) { ... })
```
`Default()` はロギングやリカバリ機能を自動でセットアップしてくれます。また、`r.GET` のようにメソッドごとにメソッドが分かれているため、標準ライブラリのような `if r.Method == ...` の分岐が不要になります。

### 02. JSON の返却 (16-18行目)
```go
c.JSON(200, gin.H{"message": "pong"})
```
`c.JSON` を呼ぶだけで、ヘッダーのセットとエンコードを一括で行ってくれます。`gin.H` はマップを手軽に書けるショートカットです。

---

## 4. 重要なTips
> [!TIP]
> 1. **`c.JSON` の魔法**: `gin.Context` を通じてレスポンスを操作するため、`http.ResponseWriter` などを直接触る必要がなくなります。
> 2. **バインド機能**: `c.ShouldBindJSON` を使うと、リクエストで送られてきたJSONを、一瞬で構造体にマッピングできます。
> 3. **パフォーマンス**: Gin は高速なルーティングエンジン（HttpRouter）を使用しており、数多くのリクエストを効率的に処理できます。

## 5. まとめ
Gin を使うと、開発スピードが劇的に向上します。標準ライブラリの知識をベースにしつつ、その進化版としてのパワーを体感してください。
