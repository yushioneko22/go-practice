# 03 Echo Basics (軽量・高機能な Echo の基礎)

このトピックでは、**「クリーンな設計と高い拡張性を持つ Echo フレームワークを使い、洗練された API を構築する方法」**を学びます。

---

## 1. なぜ必要か
`Echo` は Go のフレームワークの中でも特に「ミニマリズム」と「カスタマイズ性」に優れています。
Gin と人気を二分しており、特に **Middleware（ミドルウェア）** の扱いやすさや、**データバインド** の強力さが特徴です。Echo を学ぶことで、より「型安全」で保守性の高い Web 開発のスキルが身に付きます。

## 2. 比喩：Echo は「高性能なモジュール家具」
- **Gin**: 完成されたオシャレなカフェ。最初から色々揃っている。
- **Echo**: モジュール家具。基本はシンプルだが、自分の好きなパーツ（ミドルウェアなど）を組み合わせて、自分にとって最強の仕事場を作り上げることができる。

## 3. コード解説

### 01. インスタンス生成とルーティング (10-15行目) ★ここが一番重要
```go
e := echo.New()
e.GET("/hello", func(c echo.Context) error { ... })
```
`echo.New()` でサーバーの土台を作ります。Gin 同様、メソッドごとのルーティングが非常に簡単です。

### 02. JSON の返却 (16-18行目)
```go
return c.JSON(http.StatusOK, map[string]string{"msg": "hi"})
```
Echo では、ハンドラ関数が `error` を返す設計になっています。`c.JSON` の戻り値をそのまま `return` するのが標準的な書き方です。

---

## 4. 重要なTips
> [!TIP]
> 1. **`echo.Context`**: この中にリクエストとレスポンスのすべてが詰まっています。
> 2. **強力なロガー**: `e.Use(middleware.Logger())` を1行書くだけで、どんなリクエストが来たか、処理に何ミリ秒かかったかを非常に綺麗にターミナルへ表示してくれます。
> 3. **グループ化**: `/api/v1` のようにパスをグループに分ける機能が非常に強力です。

## 5. まとめ
Echo は、シンプルながらも大規模開発に耐えうる拡張性を持っています。Gin との違いを楽しみながら実装してみましょう。

## 演習問題 I/O
### 仕様
- `/search` というパスにクエリパラメータ `q` を渡してください。
- 入力例: `/search?q=Golang`
- 出力例: `{"query": "Golang", "results": 0}` (JSON)

## 実行方法
```bash
cd exercise
go run main.go
# ブラウザで http://localhost:1323/search?q=Golang
# (Echoのデフォルトポートは1323です)
```
