# 03 JSON Handler (JSON APIの構築)

このコードは、**「フロントエンドや他のシステムと、JSONという共通言語を使ってデータをやり取りする」**という、モダンなAPI開発の土台を実現するためのサンプルです。

---

## 1. なぜ必要か
今どきのWebアプリは、サーバーがHTMLを返すのではなく、**「データ（JSON）」**だけをフロントエンド（ReactやVueなど）に返し、画面構築はそちらに任せる「SPA（Single Page Application）」構成が主流です。そのため、Goの構造体とJSONを相互に変換する技術は必須中の必須です。

## 2. 比喩：JSONは「世界共通のコンテナ」
- **構造体 (Go)**: 日本国内（Go言語の世界）でしか通じない、中身の詰まったダンボール。
- **JSON**: 世界中のどんな船（言語/システム）にも載せられる、透明で標準的な「規格化されたコンテナ」。
- **Marshal/Unmarshal**: コンテナに詰めたり、中身を出したりする「荷役作業」。

## 3. コード解説

### 01. レスポンスヘッダーの設定 (15行目)
```go
w.Header().Set("Content-Type", "application/json")
```
「これから送るデータはJSONですよ」と相手に伝えます。これを忘れると、相手はただのテキストだと思って正しく解析してくれません。

### 02. エンコードと書き出し (20-22行目) ★ここが一番重要
```go
json.NewEncoder(w).Encode(response)
```
構造体をJSONに変換（エンコード）しながら、そのままリスポンスとして書き出します。

---

## 4. 重要なTips
> [!TIP]
> 1. **大文字開始の原則**: Phase 2でも学びましたが、JSONに変換したい構造体のフィールドは必ず **大文字開始** にしてください。小文字だと `json` パッケージから見えず、空のJSON `{}` になってしまいます。
> 2. **JSONタグの活用**: ``json:"user_id"`` のようにタグを付けることで、Go側は `UserID`、JSON側は `user_id` といった使い分けができます。
> 3. **JSONの読み込み**: 送られてきたJSONを読み込むときは `json.NewDecoder(r.Body).Decode(&data)` を使います。

## 5. まとめ
JSONを扱えるようになれば、あなたのGoプログラムは他のどんなシステムとも会話ができるようになります。

## 演習問題 I/O
### 仕様
- `/event` というパスに GET でアクセスした際、カレンダーのイベント情報をJSONで返してください。
- 構造体の例: `type Event struct { Title string, Date string }`
- 出力例: `{"Title":"Meeting", "Date":"2026-03-23"}`

## 実行方法
```bash
cd exercise
go run main.go
# 別のターミナルで curl http://localhost:8080/event
```
